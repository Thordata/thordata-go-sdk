Release v1.2.0: Complete Four Scraping Methods Support

This release completes the Go SDK implementation with all four major scraping
methods and significant improvements to code quality, documentation, and user
experience.

## Major Features

### Complete Four Scraping Methods
- ✅ SERP Search (Google, Bing, Yandex, DuckDuckGo)
- ✅ Web Unlocker (Universal Scrape with JS rendering)
- ✅ Browser Scraper (Browser connection URL generation)
- ✅ Web Scraper (Tool-based specialized scraping with 100+ pre-built tools)

### New Features
- Add `GetBrowserConnectionURL()` method for Thordata Scraping Browser integration
- Add `ValidateEnv()` function for environment variable validation with helpful error messages
- Add upstream proxy support (`THORDATA_UPSTREAM_PROXY`) for proxy chaining
- Add comprehensive example demonstrating all SDK features
- Add browser connection example

### Improvements
- Improve error handling in `execute()` function (proper `io.ReadAll` error checking)
- Streamline repository structure (remove redundant examples, clean up empty directories)
- Update documentation with clear role positioning (Infrastructure / High-Performance Networking)
- Enhance integration tests with better network interference handling
- Update `.env.example` to use unified upstream proxy port (7898)

### Code Quality
- Format all code with `gofmt`
- Add comprehensive unit tests for new features
- Improve code comments and documentation
- Ensure all files are in English
